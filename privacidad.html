Un sitio de presentación

MJON TECH no incluye cuentas, analítica publicitaria ni formularios de envío. Las preferencias visuales se mantienen solamente durante la visita. Las tipografías, imágenes y bibliotecas se sirven desde este sitio.

Contacto y enlaces externos

Al abrir WhatsApp salís de este sitio. El texto del tema elegido se incorpora al enlace, pero el envío requiere tu acción en WhatsApp. GitHub, WhatsApp y las páginas de cada proyecto aplican sus propias condiciones. GitHub Pages puede procesar información técnica necesaria para servir las páginas.

Accesibilidad y movimiento

Podés navegar con teclado, saltar al contenido y detener el globo. La preferencia de movimiento reducido se respeta; con ahorro de datos o sin WebGL se utiliza una imagen estática. Todo el contenido y los enlaces siguen disponibles sin la escena 3D.

Reportar un problema

Si encontrás una barrera de acceso, contanos qué página y dispositivo estabas usando para que podamos revisarla.
