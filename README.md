# MJON TECH · Web corporativa

## Contenido
Página principal, cuatro páginas de proyectos, contacto por WhatsApp Business con formulario validado, globo Canvas interactivo y recursos locales.

## Contacto
WhatsApp Business: +54 9 343 695-9552. El formulario prepara un mensaje para que el visitante confirme el envío en WhatsApp; no hay backend ni almacenamiento de datos.

## Publicación
Subir los archivos a GitHub Pages o hosting estático HTTPS. No requiere build. Configurar dominio propio y metadatos absolutos de Open Graph al disponer de URL pública.

## Alcance
La web es funcional como sitio de presentación, pero los proyectos que no tienen demo pública verificada muestran su estado real. El globo es Canvas 2D interactivo, no WebGPU.
